# Changelog

Все значимые изменения в проекте LogDog будут документироваться в этом файле.

## [1.1] - pending

### Исправлено
- **Поиск (Ctrl+F) больше не подвешивает программу.** Раньше с большим окном логов поиск подвисал на секунды на каждой букве, а после короткого запроса (например, одной буквы) вся программа оставалась медленной до перезапуска — даже с закрытым поиском: фильтр перестраивал окно по 3–7 секунд. Теперь поиск ждёт паузу в наборе (Enter — искать сразу), находит по 50 000 строк за доли секунды, а новые логи при открытом поиске идут без задержек.
- **Фильтр больше не подвешивает программу.** На полном окне логов он применялся до нескольких секунд, и всё это время программа не отвечала — при наборе фильтра это повторялось на каждой паузе. Теперь окно перестраивается по частям: программа отвечает, а следующая буква в фильтре сразу прерывает недоделанное.

## [1.0] - 2026-10-16

Первая публичная версия LogDog — программы, которая показывает QA логи игр на iPhone в реальном времени. Windows, macOS и Linux, без Xcode и сторонних программ.

### Что умеет
- **Логи iPhone по USB.** Выдернули кабель — видно сразу, подключили — логи продолжаются сами.
- **Полные логи Unity-игры** (Development Build) по USB или Wi-Fi — без `<private>`, которыми iOS скрывает строки игры. Ловит логи с самого запуска игры.
- **Фильтр:** `level:`, `proc:`, `pid:`, `AND` / `OR` / `NOT`, скобки. Подсветка и подсказки как в редакторе кода, применяется сам. Поиск по логам — Ctrl+F.
- **Разбор логов:** JSON деревом, отслеживание событий, подсветка слов, повторы схлопываются в «×N», время между строками, маркеры шагов (Ctrl+M), пауза без потери логов, открытие сохранённого лога.
- **Инструменты для iPhone:** очистка данных игры без переустановки, установка `.ipa` с проверкой, краш-отчёты и уведомления о новых крашах, язык и регион, профили, перезагрузка.
- **Обучение** на демо-логах прямо в программе, тёмная и светлая темы.
- **Обновления из программы** по кнопке. Для Windows — установщик и portable-версия.

### Если вы пользовались старой версией
- Настройки из версии 0.4 не переносятся: цвета, тему и фильтры нужно задать заново.
